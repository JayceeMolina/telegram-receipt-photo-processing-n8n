# Workflow export

Upload the n8n export here with this exact filename:

```
telegram-receipt-photo-processing.json
```

Export it from n8n via the workflow's **⋯** menu → **Download**, then rename the file.

The export contains n8n credential *references* (name and internal ID) but no token values, so it is safe to publish. Anyone importing it must attach their own credentials and replace the Drive folder ID and Sheet ID.
